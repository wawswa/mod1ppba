Library Loan API

REST API pencatatan peminjaman buku perpustakaan — Express.js + Supabase, di-deploy sebagai Netlify Function.

MethodEndpointKeterangan
GET/apiStatus API
GET/api/membersDaftar anggota
GET/api/booksDaftar buku
GET/api/loansDaftar peminjaman
GET /api/loans?status=Terlambat Filter peminjaman terlambat
GET /api/loans?status=Dipinjam Filter peminjaman aktif

Setiap resource juga mendukung POST (tambah), GET /:id (detail), PUT /:id (ubah), dan DELETE /:id (hapus).

Dokumentasi lengkap, contoh request/response, dan panduan instalasi tersedia di README.md repositori proyek ini.
